# 7회차 | 제미나이로 이미지 검색하기
# 왕초보 AI 활용법 (ChatGPT·Gemini) — 2026년 하반기

---

## 오늘 수업에서 배울 내용

눈으로 보고 싶은데 이름을 모를 때, 사진만 찍으면 AI가 알아서 알려줍니다!
오늘은 제미나이의 이미지 검색 기능을 배웁니다. 글자를 입력하지 않아도, 사진 한 장으로 원하는 정보를 얻는 마법 같은 기술이에요.

---

## 이미지 검색이란?

기존 검색 방법: 네이버에 '빨간 꽃 이름'이라고 글자로 입력해서 검색
이미지 검색 방법: 꽃 사진을 AI에 올리면 "이것은 장미입니다"라고 알아서 알려줌

텍스트 없이 사진만으로 정보를 얻을 수 있습니다. 이름을 몰라도, 글자를 입력하기 어려워도 됩니다!

---

## 제미나이 이미지 검색 방법

### 방법 1: 사진 첨부하기

1단계: 제미나이 앱을 열어주세요.
2단계: 입력창 옆에 있는 카메라(📷) 또는 이미지(🖼️) 버튼을 찾아 누릅니다.
3단계: '카메라로 찍기' 또는 '갤러리에서 선택'을 고릅니다.
4단계: 사진을 찍거나 갤러리에서 고릅니다.
5단계: 입력창에 궁금한 것을 입력합니다. 예: "이게 뭐야?" 또는 "이 꽃 이름이 뭐야?"
6단계: 전송 버튼을 누르면 AI가 사진을 보고 답합니다.

### 방법 2: 실시간 카메라 사용

제미나이 앱에서 카메라 아이콘을 길게 누르면, 실시간으로 카메라로 보이는 것을 AI가 분석해줍니다!

---

## 이미지 검색으로 할 수 있는 것들

### 모르는 식물, 꽃, 나무 알아보기

정원에 핀 꽃 이름이 궁금할 때
산에서 발견한 버섯이 먹어도 되는지 물어볼 때 (※ 독버섯 판별은 전문가에게 반드시 확인!)
약초나 나물의 이름을 알고 싶을 때

직접 해보기: 주변의 아무 식물이나 찍고 제미나이에 올린 후 "이게 무슨 식물이야? 특징도 알려줘."

### 외국어 번역하기

외국 식당 메뉴판 사진 → 한국어 번역
외국에서 온 편지나 안내문 → 한국어로 설명
영어로 된 약 설명서 → 한국어로 번역

직접 해보기: 영어 음식 단어를 적은 종이 사진을 찍어 "이거 한국어로 번역해줘."

### 음식 칼로리 확인하기

밥상 위의 음식을 찍고 "이 음식들 대략적인 칼로리가 얼마야?"라고 물으면 대략적인 칼로리를 알려줍니다.

### 건물, 장소 알아보기

여행 중 본 건물이나 기념물 사진을 찍으면 어떤 건물인지 알려줍니다.

---

## 더 잘 활용하는 팁

사진은 밝고 선명하게 찍어야 AI가 잘 인식합니다.
여러 가지가 섞인 사진보다 하나의 물체가 명확하게 찍힌 사진이 더 잘 인식됩니다.
"이게 뭐야?" 외에도 다양하게 물어볼 수 있습니다:
  → "이 꽃을 화분에 키우려면 어떻게 해야 해?"
  → "이 음식이 당뇨 환자에게 좋은지 알려줘."
  → "이 식물이 독성이 있어?"
