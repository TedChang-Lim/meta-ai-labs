# 20초 영상 광고 — 원리 사전

> 틀(template)이 아니라 **원리**다. 요청이 들어오면 여기서 원리 2~3개를 골라 각자의 지능으로 살을 붙인다.
> 같은 원리를 써도 소재·시점·속도를 바꾸면 다른 영상이 나와야 한다. 결과가 같으면 원리를 이해하지 못한 것이다.

## 후킹 (첫 2~3초, 하나만)

- **미완결** — 끝나지 않은 동작을 보여준다. 뇌가 결말을 요구한다
- **스케일 점프** — 아주 작은 것에서 갑자기 거대한 것으로
- **금기 위반** — 하면 안 될 것 같은 행동의 시작
- **시선 추적** — 무언가를 노려보는 시선으로 관객 시선을 끈다
- **소리 먼저** — 화면보다 소리가 사건을 먼저 알린다
- **역방향** — 결과를 먼저 보여주고 원인을 숨긴다
- **이상 상태** — 설명 없는 기형적인 장면을 그냥 둔다
- **리듬 파괴** — 규칙적 반복을 한 번 어긴다

## 전개 (가운데를 버티게 하는 힘)

- **인과 사슬** — 하나의 힘이 다음을 건드려 누적된다. 누적이 화면에 보여야 한다
- **에스컬레이션** — 같은 사건을 3번, 매번 규모를 키워서
- **압력 축적** — 물·연기·빛·소리가 화면을 채우며 한계를 만든다
- **정보 격차** — 관객과 화면 속 대상의 지식 차이
- **시점 전환** — 사물·동물·1인칭 시점으로 바꿔 익숙한 것을 낯설게

## 전환 (한 번에 뒤집기)

- **스위치** — 눈에 보이는 물리적 계기가 상태를 바꾼다
- **역전** — 받던 쪽이 주는 쪽이 된다
- **배신** — 세운 기대를 다른 것으로 확인시킨다
- **파괴** — 형태를 부숴 이전으로 돌아갈 수 없게 만든다
- **정지** — 0.3~0.6초 모든 움직임을 멈춘다. 정적이 다음 사건의 무게를 만든다

## 보상 (마지막 3~5초)

- **빛·개방** — 막힌 것이 열렸다
- **확산** — 하나가 여럿이 됐다
- **재회·접촉** — 끊겼던 것이 닿았다
- **웃음** — 예상보다 하찮은 결과
- **잔상** — 아무것도 남기지 않고 끝난다

규칙: 보상은 **형태 변화**로 증명한다. 자막·내레이션으로 설명하면 보상이 아니다.

## 배분 감각

- 후킹 2~3초 / 전개 8~10초 / 전환 1~2초 / 보상 3~5초
- 전개는 늘어지면 죽는다. 마지막 사건이 전환 **0.5~1초 전**에 오도록 시간을 계산한다
- 15초면 원리 1개, 20초면 2개까지. 3개는 산만해진다

## 검수

1. 후킹이 3초 안에 작동하는가
2. 전개에서 누적·압력·격차 중 하나가 **실제로 커지는가**
3. 전환이 한 번에 상태를 바꾸는가
4. 보상이 형태 변화로 보이는가
5. 마지막 프레임이 가장 밝거나 가장 어두운가 (중간값은 미완성)
6. 무음 창 0개인가


## 3B 법칙 (저항을 낮추는 기본기)

광고가 사람의 방어를 낮추는 세 가지 소재. **Baby · Beast · Beauty.**

- **Baby** — 아기·새끼·갓 태어난 것. 보호 본능이 먼저 작동해 판단을 끈다
- **Beast** — 동물. 인간 사회의 규칙 밖이라 위협이 안 된다. 개·고양이·새·물고기 모두 해당
- **Beauty** — 아름다움. 얼굴·빛·피부·대칭. 시선을 먼저 잡는다

쓰는 법: **후킹 3초를 3B 중 하나로 열고**, 그 다음에 메시지를 얹는다. 3B 없이 개념부터 열면 시청자는 방어 자세로 본다.

## 소재 팔레트 (매번 같은 것 쓰지 말 것)

| 영역 | 예 | 잘 먹히는 원리 |
|---|---|---|
| 우주 | 행성·우주선·무중력 | 스케일 점프, 미완결 |
| 물속 | 수면 아래·거품·빛 굴절 | 압력 축적, 시점 전환 |
| 하늘 | 구름·새·낙하 | 해방, 스케일 |
| 관계 | 연인·가족·첫 만남·이별 | 정보 격차, 재회 |
| 동물 | 개·고양이·새끼 | 3B, 웃음 |
| 일상 사물 | 컵·신발·전구·문 | 리빌, 역전 |
| 몸 | 손·눈·호흡 | 감각 이입 |
| 기계 | 톱니·스위치·도미노 | 인과 사슬 |

규칙: **최근작에서 쓴 소재는 다음 작에서 쓰지 않는다.** 같은 소재를 반복하면 원리가 아니라 습관이 된다.

## 속도

- 코드 렌더 1,200프레임은 CPU에서 약 5분. 이건 고정 비용이다
- 대신 **수정 라운드를 줄인다**: 비트시트 → 프레임 3장 확인 → 전체 렌더. 이 순서를 지키면 재렌더는 1회로 끝난다

## 실패 사례 (2026-11-23)

- **낙엽 편** — 이동만 있고 형태 변화가 없다. 후킹은 있으나 전개가 없다
- **등대 편** — 켜짐/꺼짐이라는 상태 변화뿐, 전환이 없다
- **벽 편** — 파괴까지 갔으나 결에서 화면이 어두워져 보상이 실패했다
- **도미노 편** — 인과 사슬 + 스위치 + 점등으로 닫힘. 구조는 성립
