# 카파시 LLM 위키 방식

안드레 카파시(OpenAI 창립 멤버·전 테슬라 AI 총괄)가 쓰는 정리법. 핵심은 **물을 때 찾지 말고, 들어올 때 정리한다.**

## 서재 세 칸
- `raw` — 원본을 던지는 곳. AI는 읽기만
- `wiki` — AI 사서가 정리해 쓰는 곳
- `index` — 목차
- `CLAUDE.md` — 사서에게 주는 업무 규칙서. **가장 중요한 파일**

## 원칙
- 새 자료가 오면 AI가 **기존 페이지를 고쳐 둔다** (사람은 넣고 묶기만)
- 좋은 점: 쌓일수록 좋아짐 / 그냥 글 파일이라 내 것 / 어떤 AI로든 꺼내 씀 / 복잡한 장치 불필요
- 건강검진 한 마디: 모순·낡은 내용·외톨이 페이지·끊어진 링크를 찾는다
- 약점: 사서가 빠뜨려도 **글이 매끄러워 모른다** → 모든 페이지에 원본 파일명, 모순은 덮지 말고 표시, 정기 검진
- 한계: 개인·한 분야 규모까지. 여럿이 동시에 쓰거나 빨리 바뀌는 정보엔 부적합
