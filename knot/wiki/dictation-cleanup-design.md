# 받아쓰기 정리 모드 설계 (HenaWhisper v1.3)

STT 뒤에 LLM을 붙여 군더더기를 지우는 구조. 기본은 꺼 두고 문서 앱에서만 켠다.

## 3단 모드
- `off` / `auto`(기본) / `always`
- auto 판정: 메일·워드·한글·노션·옵시디언·브라우저 = 정리 / 텔레그램·카톡·에이전트 창 = 원문
- 단축키: 오른쪽 Command = 기본 / +Shift = 이번만 정리 / +Option = 이번만 원문

## 지연 실측 (맥북 M3 Max, 한국어)
- STT Groq whisper-large-v3-turbo: 0.42~0.51초
- LLM: Groq `qwen/qwen3.8-27b` **0.38~0.65초(최속, 무료)** / DeepSeek 0.46~0.88 / gpt-oss-20b 0.55~0.89 / Gemini 1.54~1.96
- E2E: 16초 발화 1.07~1.29초, 39초 발화 1.28~1.37초

## 안전장치 3종
1. 요약 금지 + 원문 대비 70% 길이 검증
2. 고유명사 사전 치환 (새미새론·임창식)
3. 없는 숫자·메일·링크 거부 → 실패 시 **원문 그대로**

실측 사고: 39초 발화가 206자로 요약됨 / "새미새론"→"세미세론" / 없는 전화번호 생성.
