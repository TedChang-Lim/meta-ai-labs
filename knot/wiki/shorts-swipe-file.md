# 쇼츠 소재 파일 (swipe file)

잘 된 영상의 **제목·첫 3초·전개·끝맺음**만 모아 두는 재료 창고. 대본을 쓸 때 여기서 꺼낸다.

## 기록 형식
- 링크 / 채널 / 길이 / 조회·댓글
- 첫 3초에 무엇을 보여주는가
- 요구·갈등이 몇 단계로 커지는가
- 반전 지점(초)
- 우리 소재로 바꿀 때 남는 것 / 버릴 것

## 1호 — 숏박스 「너 정신 안 차릴래?」
- 84초 · 조회 179만 · 댓글 692 · 컷 중간값 1.33초
- 첫 3초: 웃는 얼굴 + "제가 뭐예요?" + 당황한 매니저
- 5단계 상승: 샌드위치 → 휴게소 → 가평 → 상주 → 씨앗
- 반전: 1:00 이후, '착한 아이'가 가장 무리한 요구
- 상세 수치: [[shorts-blueprint-sukbak]]
