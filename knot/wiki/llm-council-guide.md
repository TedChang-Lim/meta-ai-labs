> **작성자:** 해나 (Hermes)

## 1. 개요
Andrej Karpathy의 LLM Council 방법론을 Hermes 환경에 맞게 구현. 중요한 결정을 **5명의 AI 어드바이저(서로 다른 시각 + 다른 모델)** 가 동시 분석 → 교차 검증 → 종합 리포트.

## 2. Council 구성 (2026.07.09 기준)

| # | 역할 | 사고 방식 | 모델 | 가격 |
|:-:|:----:|-----------|:----:|:----:|
| 1 | **Contrarian** (반대파) | "이거 왜 망할까?" — 위험·허점·실패 요인 집중 | DS V4 Flash | $0.14/$0.28 |
| 2 | **First Principles** (기본기파) | "근본적으로 뭘 해결하는가?" — 가정 깨기 | DS V4 Flash | $0.14/$0.28 |
| 3 | **Expansionist** (확장파) | "어디까지 커질 수 있나?" — 숨은 기회·확장 | MiMo 2.5 (일반) | $0.14/$0.28 |
| 4 | **Outsider** (외부인) | "이 분야 모르는 사람 눈엔?" — 전문가 맹점 | MiMo 2.5 (일반) | $0.14/$0.28 |
| 5 | **Executor** (실행파) | "내일 아침 뭐부터?" — 실행 가능성·첫걸음 | DS V4 Flash | $0.14/$0.28 |
| 👑 | Chairman (의장) | 5개 취합→일치/충돌/맹점/최종결론 | DS V4 Flash | $0.14/$0.28 |

**Council 1회 비용:** 약 $0.015~0.025
**Cache Hit 시:** 약 $0.002 (거의 공짜)

## 3. 진입 방식 (2가지)

### A. 마스터님 직접 명령
> "야 이거 위원회 돌려봐"
> "이거 council 돌려"
> "이거 다각도로 검증해봐"

### B. 해나(에이전트) 제안
해나가 질문 맥락을 보고 "이건 검증이 필요하겠다" 판단 시:
> "이거 위원회 돌릴까요? (DS Flash 3개 + MiMo 2개로 다각도 분석, 30초면 끝납니다)"

## 4. 실행 프로세스

```
1. 질문/결정 입력
       │
2. 해나가 5개 subagent 동시 전달 (delegate_task)
       │
  ┌────┬────┬────┬────┬────┐
  C    FP   E    O    EX   ← 각자 분석 (~30초)
  │    │    │    │    │
  └────┴────┼────┴────┘
            ▼
3. Chairman 종합 → 리포트
            │
4. 마스터님께 보고
```

## 6. 언제 돌리고, 언제 안 돌리나

### 🔴 돌려야 하는 경우 (Council 트리거)
- "~할까 말까?" 결정/선택 질문
- "A vs B" 비교
- 사업/강의/전략 관련 중요한 기획
- "틀리면 돈/시간/평판 손해"가 큰 결정

### ✅ 안 돌려도 되는 경우 (일반 응답)
- 단순 사실 질문 ("날씨 어때?", "이 파일 읽어줘")
- 실행/작업 의뢰 ("이메일 보내줘", "검색해줘")
- 창작/생성 요청 ("이미지 만들어줘")
- 일상 대화
