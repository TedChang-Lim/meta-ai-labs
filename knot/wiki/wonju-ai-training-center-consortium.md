# 원주 'AI 특화 공동훈련센터' (국가인적자원개발컨소시엄)

원주시 AI 교육 사업 후보 1건. 이미 진흥원이 선정받은 사업이므로 **입찰 후보가 아니라 협력·위탁 접근 후보**로 본다.

## 확인된 사실 (연합뉴스 원문 본문 직접 열람)

| 항목 | 내용 |
|---|---|
| 사업 | 국가인적자원개발컨소시엄 **AI 특화 공동훈련센터** |
| 추진 | 고용노동부 · 한국산업인력공단 |
| 선정 | (재)원주미래산업진흥원 — 원주시 발표(2026-03-31), **강원 지역 최초** |
| 기간 | 2026~2028년 (3년) |
| 대상 | 협약기업 **재직자** |
| 특화 | 강원권 자동차·미래모빌리티 / 제조 품질·공정 혁신 |
| 과정 예 | 생성형 AI 활용 품질 업무 자동화, 디지털트윈 기반 품질검사, 불량 원인 분석, '지능형 제조 품질 전문가' 양성 |
| 금액 | 기사 본문 "2026~2028년까지 총 **15억원**의 국비" (원주시 발표 인용) |

사업 성격: 훈련 기반을 갖춘 기관이 협약기업 재직자에게 현장 맞춤형 AI 훈련을 제공하고, 기업 AI 도입 수준 진단 → 훈련 → 현장 적용까지 연계하는 실전형 지원체계.

## 우리 쪽 접근 여지

- 진흥원은 **선정·운영 주체**, 실제 훈련은 협력 기관·강사·과정 단위로 나뉠 수 있다 → 훈련기관·강사·과정 협력 파트너로 접근.
- 대상이 재직자·제조 품질이므로 왕초보 시민강좌가 아니라 **기업 실무 과정**으로 커리큘럼을 짜야 맞는다.
- 참고: [[lecture-fee-standard]], [[kacec-capability]]

## 미확인 (확정값으로 쓰지 않음)

- **15억원은 언론 보도값**이다. 원주시 보도자료·HRD4U 신규모집 공고 **원문으로는 확인하지 못했다**.
- 확인 시도 2건(2026-11-22): ① 원주시청 공고·보도자료 원문 미검색 ② HRD4U 해당 공지(`제2006-008호` 관련 설명회 질의응답)는 본문에 지원 규모 없이 첨부 PDF(`AI 특화 공동훈련센터 사업 설명회 주요 질의응답.pdf`, 90,025B)만 걸려 있고 미열람.
- 웹 추출 백엔드(ddgs)가 검색 전용이라 페이지 본문 추출 실패 → `curl` 직접 요청으로 두 페이지 모두 HTTP 200 확보, 연합뉴스 본문만 파싱 성공.
