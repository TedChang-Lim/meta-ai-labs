# 🚨 [긴급 공지] OpenCode Go API 정책 변경 및 개인 API 키 발급 가이드

> **적용 일시:** 2026년 10월 20일  
> **대상:** 0원 무적 에이전트 정예팀 전원 (AG 제외 전 에이전트가 OpenCode Go API 기반 구동 중)  
> **상황:** 기존 서비스 계정 기반 OpenCode Go API 키가 만료(Invalid/Expired)되어 모델 호출 불가 상태 발생.  
> **원인:** OpenCode Go 플랫폼 정책 개편 (서비스 계정 전용 키 체제 → 개인 API 키 체제로 전환)

---

## 📌 1. 플랫폼 정책 변경 핵심 내용

1. **기존 방식 (만료됨):**
   - API 키가 서비스 계정(Service Account)에만 속해 있었으며, 소유자(Owner)와 관리자(Admin)만 관리 가능했음.
   - 기존에 발급받아 쓰던 공용 서비스 계정 API 키가 일괄 만료 처리됨.

2. **신규 방식 (개인 API 키 도입):**
   - 이제 **모든 구성원(Member)이 자신만의 개인 API 키(Personal API Key)를 직접 생성**할 수 있음.
   - **개인 키 작동 원리:**
     - 개인 키를 사용하면 해당 사용자 계정의 권한/예산으로 모델을 호출합니다.
     - 사용자의 사용량, 예산 및 모델 규칙이 적용됩니다.
     - 멤버십 키는 모델 목록을 보고 호출하는 기능만 제공합니다.
     - 워크스페이스를 탈퇴하면 해당 키는 자동으로 취소(무효화)됩니다.
   - **관리자 권한:**
     - 소유자 및 관리자는 `설정` → `회원` 페이지의 `API 키` 섹션에서 회원의 키를 확인하고 필요 시 취소할 수 있습니다.

---

## 🔑 2. 새 개인 API 키 생성 절차 (마스터님 작업 가이드)

에이전트들이 API를 정상 복구하기 위해 마스터님 계정에서 신규 개인 API 키 생성이 필요합니다:

1. **OpenCode Go 로그인** 후 웹 콘솔 접속
2. 오른쪽 상단 모서리에 있는 **계정 메뉴** 열기
3. **계정** → **개인 API 키 (Personal API Keys)** → **API 키 추가 (Add API Key)** 클릭
4. **`Anomaly`** 워크스페이스가 선택된 상태에서 `API 키 추가` 대화 상자가 나타남
5. 새 API 키 발급 완료 후 키 복사
6. 각 에이전트 환경 변수 및 설정 파일에 신규 키 등록
