## 한 줄
정본은 맥(`~/초보프로젝트/강의자료실`), 사이트(`semiseron.kr/lecture`)는 사본. `올리기.sh` 한 번으로 밀어 올린다.

## 자리
- 강의안 원문 `강의자료실/docs/*.md` → 빌드하면 페이지 + 내려받기 텍스트 생성
- PPT 정본 `강의자료실/ppt_정본/*.pptx` (회차 번호를 앞에 붙임)
- 사이트 사본 `meta-ai-labs/lecture/` (암호문 html + `files/` + `ppt/`)
- 비밀번호는 맥 키체인 `semiseron-lecture`에만. 파일·커밋에 남기지 않음

## 올리는 법
`cd ~/초보프로젝트/강의자료실 && ./올리기.sh`
→ 빌드 → staticrypt 암호화 → 사본 동기화 → 커밋·푸시 (페이지당 1분 안에 반영)

- 과정 탭 3개: 정규(34) · 홈페이지(4) · 별도(1)
- 카드 한 줄 = 회차번호 + 제목 + [열기] + [자료 받기 → 텍스트/PPT]
