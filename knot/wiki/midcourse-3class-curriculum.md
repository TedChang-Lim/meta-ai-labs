# 중급 3반 커리큘럼 (2026 겨울)

왕초보를 끝낸 사람이 다음에 들을 과정. 8주 · 주 1회 2시간 · 월 10만원(2개월 20만원 완납), 도구 구독 별도.

- **1반 실전 글쓰기반** — 클로드. 맥락 설계·출력 양식 제어 → 블로그/공모전 글 1편
- **2반 비주얼 아트반** — 챗GPT. 화풍·구도·조명 제어, 일관 캐릭터 → 고화질 이미지 10장
- **3반 AI 영상반** — 클링. 이미지·텍스트→영상, 카메라 무빙 → 클립 1편 (컷 편집 제외)

공통 미션: 최종 작품을 실제 공모전에 응모, 8주차에 응모 완료 화면 확인.
교수진: 임창식 원장 총괄 / 김소영 이사장 글쓰기 집중지도 / 한계얼 이사 격월 특강.
로드맵: 왕초보 → 중급 8주 → 상지대 평생교육원 상급(컷편집·사운드·출판).
