## 배선

`cron_briefing.py`에 추가한 것:

- `load_recent_archive(days=7)` — archive/*.json에서 기사 묶음 수집, 제목 중복 제거
- `top_keywords(items, n)` — 빈도 후보 추출. **반드시 n개를 채운다** (덜 채우면 낡은 키워드가 남는다)
- `generate_weekly(recent, win, kw_candidates)` — 카드 3개 + 키워드 4개 + 쉽게 읽기
- `window` 필드 — 집계 구간·건수를 화면에 표시

`briefing.html`에 추가한 것:

- `#tickerBar` 속보 띠
- `d.cards` / `d.keywords` / `d.easy` 바인딩
- `#wkMeta` 집계 구간 표시
- 면 라벨(`seclabel`) 동적 갱신
- `#archive` 앵커 (카드 출처 링크 대체용)

## 함정

**1. `srcrow` innerHTML 교체가 쉽게 읽기 버튼을 지운다**
출처를 `innerHTML`로 갈아끼우면 안에 있던 `.easybtn`이 사라진다.
`keepBtn`으로 잡아두고 다시 붙여야 한다.

**2. 키워드를 덜 채우면 낡은 값이 남는다**
버튼은 항상 4개다. 3개만 넘기면 네 번째는 9월 값 그대로다.
`top_keywords`는 기준을 단계적으로 낮춰 **반드시 n개**를 채운다.

**3. 루트 도메인 링크는 기사 링크가 아니다**
LLM이 `https://techcrunch.com/`만 주는 경우가 많다.
`^https?://[^/]+/?$` 로 걸러내고 `#archive`로 돌린다.

**4. 정적 fallback을 지우면 안 된다**
JSON에 `cards`가 없으면 HTML에 박힌 9월 내용이 그대로 보인다.
`var DIGEST={...}` 기본값을 남겨두고 JSON이 오면 덮어쓴다.

**5. 아카이브는 배포 폴더에만 인덱스가 있다**
`archive-index.json`은 `meta-ai-labs`에만 생긴다. 로컬 폴더에서 서빙하면 404가 뜬다(정상).
