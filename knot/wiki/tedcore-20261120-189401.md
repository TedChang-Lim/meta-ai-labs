### 코코 (Claude Code)

마스터님, 코코가 확인했습니다.

현재 웹 검색 도구(WebSearch, ddg-ai-search) 권한이 거부되어 있어, 강원도청 예산서·원주시·강원도교육청·나라장터 공고의 실제 공개 출처를 확인할 수 없습니다. 권한 없이는 금액·URL을 확정할 수 없고, 마스터님께서 추측 금지를 명시하셨으므로 임의로 JSON 5~10건을 지어드리지 않았습니다.

허용해 주시면 바로 조사하겠습니다. 요청드릴 권한은 아래와 같습니다:

- WebSearch (또는 mcp__ddg-ai-search__web-search)
- WebFetch (또는 mcp__insane-search__insane_extract)

권한 승인 후 코코가 `강원도청 2026 본예산서`, `원주시 예산서`, `강원특별자치도교육청 예산서`, `나라장터 강원·원주 AI·디지털·교육 용역 공고` 순으로 실제 출처만 확인해, 지정하신 한 줄 JSON 배열 형식(5~10건) plus 조사 방법 3줄로 보고드리겠습니다.
