# 스레드 링크 5건 (2026-11-21 수집)

마스터님이 보내온 스레드 링크 5건 정리. 1번은 별도 페이지로 깊게 남겼다.

## 1. 제미나이 노트북 — 자료로 사이트 만들기
- 링크: threads.com/share/BAana3WhXO (huh_kwan, 조회 5.2만)
- 요지: 노트북LM 채팅에 "사이트 만들어 줘" → 메모·자료 기반 웹페이지 생성. 링크트리도 만든다는 후기
- **공식 확인 완료** (2026-11-16 구글 발표, 웹·18세 이상, 모바일 예정) → [[gemini-notebook-interactive-sites]]
- 우리에게: **강의 실습 소재로 바로 쓸 수 있음**. 마스터님이 노트북LM을 자주 쓰시므로 기능 숙지는 필수

## 2. 도시 블록 디오라마 영상 (ChatGPT 이미지 → Flow 영상)
- 링크: threads.com/share/BAkXjUuMnj (jh_aicafe, 조회 1.2만)
- 요지: ChatGPT에 도시명만 넣어 "블록으로 조립한 미니어처 도시" 이미지 → **구글 Flow Omni 1.2 Flash**로 10초 원테이크 영상. 매일 50크레딧 무료(구독 무관)
- 프롬프트 핵심: 이미지 = 블록 질감·랜드마크 / 영상 = 첫 1초 유람선 뱃고동 → 강물 스치며 이동 → 마지막 2초 상승해 63빌딩 전경, 피치카토+물소리+한국어 내레이션
- 우리에게: **새미새론 홍보 숏폼**에 그대로 응용 가능(도시명만 바꿔 지역 소재). Flow 크레딧은 매일 리셋되므로 초안은 360p로 뽑는 원칙 유지

## 3. PPT에 HTML 넣기
- 링크: threads.com/share/BAWuVkmUio (autoxsea, 조회 5.3만)
- 요지: 파워포인트에 HTML을 넣어 **애니메이션·효과 표현**을 대체. "PPTX로 접근하면 안 됐다"는 댓글 — 즉 슬라이드 파일 자체가 아니라 웹 개체로 얹는 방식. 작성자는 스킬 공유 예정
- 우리에게: **지금 만드는 강의 덱과 직접 연결**. 다만 발표장 PC에서 인터넷·보안 정책에 걸릴 수 있으니 **행사장 사전 확인 필수**(자연학습원 배움마루 노트북 환경)

## 4. 코드로 만드는 크리스마스 뉴욕 거리 영상
- 링크: threads.com/share/BAWZMT3sVo (zakugio, 조회 1.8천)
- 요지: "코드로 크리스마스 뉴욕 거리 분위기를 영상으로 만들어" → 클로드 코드가 장면을 코드로 렌더. 퍼블릭도메인 BGM(Jingle Bells, 1857) 자동 추가. 이어서 "거리에 사람들이 지나다니는 루프 영상 추가" 프롬프트로 확장
- 우리에게: **code-rendered-scene-video 방식의 실사례**. 배경음악 라이선스 걱정 없이 쓰는 법(퍼블릭도메인 명시)이 특히 참고됨

## 5. 27년 예산편성 사업을 지도에 얹기
- 링크: threads.com/share/_mMb5fJBD (sungh.w, 조회 2.8천)
- 요지: 2027년 예산편성현황을 읽어 **예산 잡힌 사업을 지도에 표시**, 도로·철도 연결, 농업진흥구역 해제·도심 확장으로 지가가 오르는 곳 파악. 예산 확보/미확보 사업 분류. PPT 370여 장
- 작성자 후속: 인프라 사업(국도·철도·산단·공항·항만·공공기관 이전) 정리, **26년 대비 3배 이상 = 다음 단계, 8배 이상 = 착공 신호**로 해석
- 우리에게: 원주·강원 부동산·정책 분석에 같은 방식 적용 가능. 다만 **해석 규칙(3배/8배)은 작성자 개인 기준**이므로 사실로 인용하지 말 것
