# TED CORE 세션 지식화 (session → knot)

TED CORE에서 끝난 작업 세션을 다모아(knot) 지식 페이지로 자동 변환하는 기능.

## 왜 만들었나

세션이 TED CORE 안에만 쌓이면 나중에 "그때 그 일을 어떻게 했지"를 꺼낼 수 없다.
마스터님이 같은 맥락을 매번 다시 설명해야 하고, 새로 붙는 에이전트도 이력을 모른다.
그래서 작업 기록을 `note` 타입 지식 페이지로 옮겨, 사람과 에이전트가 같은 곳에서 찾게 한다.

## 어떻게 동작하나

1. TED CORE 좌측 '세션' 패널에서 **지식화** 버튼을 누르거나,
   작업 실행 패널의 **지식화** 체크가 켜져 있으면 작업이 끝난 뒤 자동 실행된다.
2. RPC `session.knowledge {id}` 가 `src/knowledge.rs` 의 `write_from_session()` 을 부른다.
3. 세션 JSON만으로 페이지를 만든다 — 에이전트에게 다시 묻지 않는다(환각 없음, 비용 0원).
4. `knot/wiki/<슬러그>.md` 생성 → `index.md` 의 `## note` 절에 1줄 등재 → `log.md` 에 append.
5. 같은 세션을 다시 지식화하면 페이지는 **갱신**, index·log 는 **중복 없이** 그대로 둔다.

## 페이지 구조

| 절 | 내용 |
|:--|:--|
| frontmatter | `type: note`, created/updated, `trust: unreviewed` |
| 무엇을 했나 | 시각, 참여 에이전트, 리더, 발화 수 |
| 지시 | 첫 사용자 지시 300자 |
| 답한 사람 | 에이전트별 응답 시간·길이·상태 표 |
| 답변 발췌 | 에이전트별 700자 (전문은 세션 JSON에 남음) |
| 결정과 다음 할 일 | **비워 둠 — 사람이 채운다** |
| 관련 | 실재하는 위키 페이지만 `[[링크]]` |

## 설계상 지킨 것

- 요약을 LLM에게 다시 시키지 않는다. 자동 요약은 환각 위험이 있고 비용도 든다.
- 슬러그는 `tedcore-YYYYMMDD-<id끝6자>` ASCII로 고정 — 한글 제목이 파일명을 흔들지 않게.
- 끊어진 링크를 만들지 않는다. `wiki/` 에 실제 파일이 있을 때만 링크한다.
- `trust: unreviewed` 로 시작한다. 사람이 확인하면 올린다(master는 마스터만).

## 검증 (2026-11-22)

- `cargo test` 7건 통과 (지식화 3건 포함)
- 임시 vault(`TED_KNOT=/tmp/knot-test`)에서 실제 세션 `s1795213189401` 변환 → 페이지·index·log 생성 확인
- 같은 세션 재호출 → `created:false`, index·log 중복 0 확인
- 실 vault 에 1건 적용: `wiki/tedcore-20261120-189401.md`

## 남은 것

- `graph.html` 은 손으로 만든 개념 지도라 위키 페이지가 자동으로 붙지 않는다.
  위키 링크 그래프를 자동 생성하려면 별도 스크립트가 필요하다(미착수).
- '결정과 다음 할 일' 자동 초안은 아직 없다. 넣으려면 LLM 호출이 필요해 비용 판단이 먼저다.
